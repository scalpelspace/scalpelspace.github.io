Momentum

momentum

A Uno-style footprint sensor shield that bridges an SPI or CAN host to sensor telemetry, combining a 9-DOF IMU, multi-constellation GNSS, and a barometric pressure sensor on a single board.

  • 9-DOF IMU via the BNO086.
  • Multi-constellation GNSS via the SAM-M10Q.
  • 24-bit barometric pressure via the BMP390.
  • SPI or Classic CAN host interface.
  • Firmware updates over USB-C via the CP2102N.
  • Jumper selectable 5 V or 3.3 V SPI logic level.

SPI-CAN Breakout

can_hat_mini

A small-footprint, breadboard-friendly breakout that bridges an SPI host to a CAN bus, letting any microcontroller with SPI talk CAN without an integrated controller.

  • Classic CAN and CAN FD via the MCP2518FD.
  • Miniature breadboard-compatible footprint.
  • Switch selectable bus termination.
  • Jumper selectable 5 V or 3.3 V logic level.
  • Jumper selectable silent mode for bus monitoring.

SPI-CAN 40-pin Hat

can_hat_40

A 40-pin GPIO hat that adds a CAN bus interface to single-board computers such as the Raspberry Pi series. It seats directly on the standard header and bridges the host SPI bus to a CAN transceiver.

  • Standard 40-pin (2x20) GPIO header.
  • Classic CAN and CAN FD via the MCP2518FD.
  • Switch selectable bus termination.
  • Jumper selectable silent mode for bus monitoring.
  • Fixed 3.3 V logic.
