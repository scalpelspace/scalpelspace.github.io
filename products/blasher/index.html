Blasher

blasher

  • Tools

A browser based firmware flashing and utility tool for ScalpelSpace STM32 boards. It talks to hardware directly over Web Serial, so there is nothing to install and no toolchain to set up.

  • Runs in the browser over Web Serial, with no install and no local Python environment.
  • One tool across the range, replacing the per-board flashing scripts that came before it.
  • Supported on ScalpelSpace STM32 boards.
  • Served over HTTPS, which Web Serial requires.
